## Build Now (MVP features)
- Freemium: “1‑Hour Exam Recovery Blueprint”
  - Upload (PDF/JPG) + 3–5 intake Qs.
  - Output: top 1–2 weak concepts, 3×20‑min tasks, 5 curated links.
  - Delivery: on‑page + PDF + email (fast TTV = higher value) [$100M Offers, Page 65]; multi‑format boosts engagement [$100M Leads, Page 43].
- Paid: “Complete Study Blueprint + Sprint Pack” ($19–39)
  - Full ranked priorities, 3–5 Sprints (total 3–5 hrs), 20–30 links, printable checklist.
  - Light guarantee on checkout: “If it doesn’t reveal 3 high‑yield fixes you didn’t know, 7‑day refund.” Increases perceived likelihood of success [$100M Offers, Page 59].
- High‑contrast upsell card on the free result page.

## Tech tasks (Replit-friendly)
- Routes
  - POST /api/upload (store file, intake; return uploadId)
  - POST /api/generate-mini (build Quick Blueprint; return HTML + PDF URL)
  - POST /api/checkout (create Stripe session for Complete Blueprint)
  - POST /api/webhook/stripe (on success: generate Complete Blueprint, email)
  - GET /api/admin/review (list low‑confidence), POST /api/admin/approve
- Services
  - Extractor: basic PDF text parse + concept match (confidence score). If low → review queue (Wizard‑of‑Oz).
  - Renderer: HTML templates → PDF (e.g., Puppeteer/Playwright).
  - Mailer: send Quick + Complete with links.
- Data model (simple)
  - users, uploads{fileRef,intake,status,confidence}, plans{kind:'quick'|'complete',concepts[],sprints[],links[],pdfUrl,deliveredAt}, resources{concept,url,type,quality}, orders{amount,status}.
