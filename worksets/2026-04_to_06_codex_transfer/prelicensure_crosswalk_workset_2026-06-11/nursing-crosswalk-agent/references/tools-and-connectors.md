# Tools and Connectors

## Source priority
1. uploaded workbook/pdf files in the current task
2. file library workbooks and connected internal files
3. connected drive/docs for recent or live variants
4. public web only for external standards or official public guidance

## Tool selection
- use internal file search first for uploaded/library/internal sources
- use connected drive when you need the latest live internal doc or sheet
- use spreadsheet tooling for workbook edits and qa
- use layout-preserving extraction for pdf/manual tocs
- use public web only when internal sources cannot answer the question

## Guardrails
- never let a public source override a better internal source for internal naming or mapping
- keep provenance for every merged source family
- when an internal source is incomplete, say so explicitly
