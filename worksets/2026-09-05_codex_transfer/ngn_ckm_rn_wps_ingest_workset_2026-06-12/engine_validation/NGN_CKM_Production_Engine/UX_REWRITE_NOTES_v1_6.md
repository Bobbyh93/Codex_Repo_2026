# Version 1.6 Front-End Rewrite Notes

## Purpose
This release shifts the interface from a technical dashboard into a guided curriculum lesson production workflow.

## Completed changes
- Six numbered workflow tabs: Add content, Select scope, Build settings, Build package, Results, Help and settings.
- No prefilled specific topic examples in the user interface.
- Data Chunker Pro intake folder is the recommended default path.
- Bundled taxonomy and concept indexes are visible as application assets.
- OpenAI application programming interface key field is available in Settings.
- Question-mark hover tips and More info field guide links are built in.
- Long-running actions show explanatory loading states.
- Dropdowns, switches, and select-all checkboxes are prioritized over free-text fields.

## Known limitation
Requested output switches are visible, but the backend still generates the standard complete production bundle. Selective output suppression should be implemented later if needed.
