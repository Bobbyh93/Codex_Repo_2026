# Bundled taxonomy and concept data

This folder ships with the app so a separate taxonomy upload is not required for normal use.

Included files:
- master_taxonomy_base.csv
- default_topic_catalog.csv
- concept_module_catalog.json
- nclex_taxonomy.json
- ncjmm_map.json
- source_index.json

Use master_taxonomy_base.csv as the default source/control table when no uploaded workbook is available.

Additional template:
- course_content_master_template.xlsx
