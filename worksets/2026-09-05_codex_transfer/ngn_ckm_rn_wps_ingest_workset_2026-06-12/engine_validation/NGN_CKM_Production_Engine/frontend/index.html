Curriculum Lesson Production Studio

Put content in. Pick a topic. Click build. The app cleans the source, detects topics, creates lesson materials, and writes curriculum records.

So easy a caveman could do it

1. Use the built-in topics, or send Data Chunker Pro JSON into the one intake folder.
2. Pick one topic and subtopics.
3. Click Build.

The app uses the ChatGPT API when available to clean chunks, detect topics, standardize subtopics, preserve source anchors, and reduce manual entry.
