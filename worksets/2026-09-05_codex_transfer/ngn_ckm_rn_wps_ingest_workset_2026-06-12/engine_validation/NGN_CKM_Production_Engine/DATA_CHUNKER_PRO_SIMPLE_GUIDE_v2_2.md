# Data Chunker Pro Simple Guide

Use Data Chunker Pro only when you are bringing brand-new source documents into the app.

## Easiest path

If you only want to build lessons from the bundled curriculum topic catalog:

1. Open the app.
2. Click **Use built-in topic list**.
3. Click **Load built-in topics**.
4. Pick a topic.
5. Click **Build package**.

No Data Chunker Pro is required.

## Data Chunker Pro path

Use this path only when you have new source files that need to be chunked.

1. In the app, click **I used Data Chunker Pro**.
2. Click **Copy intake folder path**.
3. Open Data Chunker Pro.
4. Set the Data Chunker Pro output folder to the copied path.
5. Set output format to JSON.
6. Run Data Chunker Pro.
7. Return to the app.
8. Click **I ran Data Chunker Pro - process files**.
9. Pick one detected topic.
10. Click **Build package**.

## Do not use generated output files as input

Do not use files like:

- `knowledge_cards.csv`
- `card_sources.csv`
- `deck.pptx`
- `answer_key.md`

Those are results, not source content.
